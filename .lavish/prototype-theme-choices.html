Ferry: xload Learns to Write

Two years ago I wrote about xload, which fills an annotated Go struct from env vars, query params, files, anything you put behind a Loader.

This sample starts with an excerpt from your writing to test the reading experience. The supporting copy, illustrative code, and callout below are prototype content.

One model, two directions

A personal site has to make room for the details. The project summary gets you interested; the article gives the explanation space to breathe.

type Config struct {
    Port int
    Host string
}

This is illustrative Go syntax for evaluating code typography, not a verified usage example of the library. Long code scrolls inside its own frame.

A shared article system.
Engineering, DIY, and personal stories use the same reading template. Specialized content uses a small, documented set of figures, code blocks, and asides.

A page that works without decoration

Ordinary writing should require Markdown and metadata. A new post should look complete without a custom illustration, bespoke layout, or interactive demo.
