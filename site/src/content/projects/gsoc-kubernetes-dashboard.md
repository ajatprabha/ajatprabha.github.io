During Google Summer of Code 2019, I worked on custom plugin loading for Kubernetes Dashboard and related Kubernetes contributions.
The project explored how a plugin framework could extend the Dashboard UI and use third-party APIs.

## Project archive

The original progress journal remains available in the [GSoC project archive](https://ajatprabha.in/gsoc-meta-k8s/).
It records the project's scope and progress separately from this site.

Kubernetes Dashboard is an upstream project with many contributors.
This page describes my GSoC work within that project.
